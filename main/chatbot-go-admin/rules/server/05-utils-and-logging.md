# Go 工具包与日志规范

## 1. 工具包约定

- 工具函数放在 `internal/util`，按职责拆包（如 `password`、`validate`、`fileupload`）。
- 工具函数保持无状态、纯函数优先，避免隐藏全局状态。
- 禁止将业务逻辑塞进 util 包。

## 2. 常见能力规范

- **密码处理**：统一使用 `bcrypt`（`GenerateFromPassword` / `CompareHashAndPassword`），禁止自定义不安全加密。
- **字符串与参数校验**：复用统一校验函数，避免到处散落正则。
- **文件上传**：限制扩展名、大小、目标目录；上传目录由配置驱动，禁止硬编码绝对路径。

## 3. 日志规范

- 统一使用结构化日志（推荐 `zap`）。
- 日志级别：
  - `debug`：开发排查信息；
  - `info`：关键业务流程；
  - `warn`：可恢复异常；
  - `error`：失败且需要关注。
- 错误日志必须带 `error` 字段；请求日志必须带 `request_id`。

## 4. 环境策略

- 开发环境可输出到控制台 + 文件。
- 生产环境优先文件或日志平台采集，避免噪声级 debug 日志。

## 5. 禁止项

- 禁止使用 `fmt.Println` 输出业务日志。
- 禁止打印密码、token、密钥等敏感信息。
