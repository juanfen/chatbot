# Go Schema 启动校验规范

## 1. 约定

- Schema 目录：`server/resources/schema/`
- 单表单文件：每个业务表对应一个 `{表名}.sql`
- 文件内容：该表完整 `CREATE TABLE` + 基础数据 `INSERT`
- schema 文件是表结构唯一真相源

## 2. 启动时行为

应用启动并建立数据库连接后执行 Schema 校验：

1. 扫描 `schema/` 下所有 `*.sql` 文件，得到应有表集合。
2. 对每张应有表：
   - **表不存在**：执行对应 SQL 文件完成建表与基础数据初始化；
   - **表已存在且结构一致**：通过；
   - **表已存在但结构不一致**：启动失败，输出差异明细与建议 SQL。
3. 校验器禁止自动执行 `ALTER TABLE` 修改线上结构。

## 3. 差异检查维度

- 列是否存在；
- 列类型是否一致；
- 可空性是否一致；
- 默认值是否一致（必要字段）。

## 4. 开发流程要求

- 新增表：必须先新增 `schema/{表名}.sql`。
- 修改表：必须先修改 schema SQL，再执行数据库变更。
- 建议 SQL 仅供人工审核后执行，不允许盲目自动执行。

## 5. 与数据库规范联动

- 表结构规范以 [04-database-and-gorm.md](04-database-and-gorm.md) 为准。
- 本启动校验在开发与生产均应启用，避免“代码与库结构漂移”。
