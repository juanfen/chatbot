# 前端提示词规范（管理后台 + 极简 SaaS 落地页）

本规范融合“管理后台提示词”与“极简 SaaS Landing 提示词”，用于统一生成高质量前端界面。

---

## 1. 共享基础规范（两类页面都适用）

- 字体体系：优先使用 Inter，保持 700/600/500/400 的清晰层级。
- 颜色控制：主色蓝系，语义色仅用于状态表达，不做大面积主背景。
- 组件风格：禁止花哨渐变、禁止高饱和拼色、禁止过度阴影。
- 交互可读性优先：hover、focus、active 状态必须明确但克制。
- 图标规范：优先 Lucide 线性图标，禁止 emoji 和彩色插画风图标。

---

## 2. 管理后台模式（Admin Dashboard）

### 2.1 布局

- 固定左侧边栏：宽度 `240px`，背景 `#1e293b`。
- 顶部导航：高度 `60px`，白底，底边框 `#e5e7eb`。
- 主内容区：背景 `#f8fafc`，内边距 `24px`。

### 2.2 色彩

- 主色：`#3b82f6`（仅按钮、链接、激活态）。
- 语义色（仅徽章/状态）：
  - success：文字 `#059669`，背景 `#d1fae5`
  - warning：文字 `#d97706`，背景 `#fef3c7`
  - error：文字 `#dc2626`，背景 `#fee2e2`
  - info：文字 `#2563eb`，背景 `#dbeafe`
- 中性色阶：`#111827 / #374151 / #6b7280 / #9ca3af / #e5e7eb / #f9fafb`
- 禁止把语义色作为整块背景填充。

### 2.3 组件

- 卡片：白底、`1px solid #e5e7eb`、圆角 `8px`、`shadow-sm`。
- 表格：表头 `40px`，行高 `52px`，行背景透明与 `#f9fafb` 交替。
- 按钮：主按钮实心、次按钮描边，禁止渐变按钮。
- 输入框：边框 `#d1d5db`，focus ring 为 `#3b82f6`（2px offset）。

### 2.4 字体与间距

- 页面标题：`20px/700`
- 分区标签：`11px/600`，大写，`letter-spacing: 0.08em`，颜色 `#6b7280`
- 表格内容：`14px/400`
- 辅助文字：`12px/400`，颜色 `#9ca3af`
- 卡片内边距 `24px`，区块间距 `24px`，表格单元格内边距 `12px 16px`

### 2.5 表格专项约束（强制）

- 表头 sticky，背景 `#f9fafb`，底边框 `2px solid #e5e7eb`。
- 行 hover 背景：`#f1f5f9`。
- 操作列固定宽度、右对齐，仅放图标按钮。
- 状态列必须使用 badge 组件，禁止裸文本状态。

---

## 3. 极简 SaaS 落地页模式（Minimal SaaS Landing）

### 3.1 背景与布局

- 页面全局背景纯白 `#ffffff`。
- 区块分隔仅使用 `1px solid #f1f5f9` 横线，不使用不同底色分区。
- 最大内容宽度 `1120px` 居中。
- 区块上下留白至少 `80px`。

### 3.2 字体

- Hero 标题：`48-56px`，`700`，`letter-spacing: -0.03em`，颜色 `#0f172a`。
- 分区标题：`28-32px`，`700`，`letter-spacing: -0.02em`。
- 正文：`16-17px`，`400`，`line-height: 1.65`，颜色 `#475569`。
- Label/Overline：`11px`，`600`，大写，`letter-spacing: 0.1em`，颜色 `#2563eb`。

### 3.3 色彩与按钮

- 主色：`#2563eb`
- 正文深色：`#0f172a`
- 正文中灰：`#475569`
- 辅助浅灰：`#94a3b8`
- 边框：`#f1f5f9`
- 主按钮：`#2563eb` 白字，圆角 `8px`，无渐变无阴影。
- Ghost 按钮：纯文字 + 图标，无边框无背景。
- 每个页面区块仅允许一个主 CTA。

### 3.4 图标与组件

- 仅使用 Lucide 线性图标，`strokeWidth: 1.5`。
- 功能卡图标 `18px`，文内图标 `16px`。
- 功能卡：白底、`1px #f1f5f9` 边框、圆角 `10px`、内边距 `24px`。
- 图标容器：`36x36`，背景 `#eff6ff`，圆角 `8px`，图标 `#2563eb`。
- 导航栏：白底，底边框 `1px #f1f5f9`，高度 `60px`。
- 可信背书条可用 `#f8fafc`，并加顶部边框 `1px #f1f5f9`。

### 3.5 禁止项（强制）

- 禁止玻璃拟态（glassmorphism）。
- 禁止深色大区块（footer 可例外）。
- 禁止 Hero 背景图或渐变背景。
- 禁止除交互元素外的大面积阴影；交互元素阴影仅允许 `0 1px 3px rgba(0,0,0,0.06)`。

---

## 4. 同项目混合场景建议

- 后台与落地页共享基础 token（字体、圆角、间距尺度），但保持独立布局体系。
- 后台强调信息密度与效率；落地页强调品牌表达与转化路径。
- 通过页面级主题变量切换，而不是在单页混搭两套视觉规则。
